# unsorted — Telegram Business бот

Бот для Telegram Business: сохраняет удалённые и изменённые сообщения собеседников, спасает одноразовые фото и видео, а ещё помогает прямо в переписке — переводит, расшифровывает голосовые, проверяет файлы и ссылки, собирает списки.

Стек: Python 3.11+, aiogram 3, SQLite. Бот работает через Telegram Business API (подключается в «Настройки → Telegram Business → Чат-боты»).

## Возможности
- 🗑 история удалённых и изменённых сообщений;
- 🔥 сохранение одноразовых медиа;
- 🌐 перевод в чате: `+перевод& текст` (ru→en), `+&перевод текст` (en→ru), `+оригинал` — вернуть исходный текст;
- 🎙 расшифровка голосовых и кружков: ответить на сообщение командой `+распознать&` (faster-whisper, на своём сервере);
- 🔍 проверка файлов на вирусы без запуска: ответить на файл командой `+проверка&` (разбор структуры + ClamAV; apk, exe, архивы, pdf, документы);
- 📝 список из перечисления: ответить на сообщение командой `+список&`;
- 🛡 защита от фишинга: предупреждения об опасных ссылках;
- 💎 тарифы: базовый и Premium (оплата Telegram Stars), промокоды, рефералы, достижения, обратная связь, экспорт переписки.

## Установка
```bash
git clone <этот репозиторий> && cd unsorted-bot
python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN="токен от @BotFather"
# в modules/01_core.py поставь свой ADMIN_ID и OWNER_CONTACT
python3 bot.py
```
Запуск как служба — через systemd (`ExecStart=/путь/venv/bin/python3 /путь/bot.py`).

## Структура
`bot.py` — загрузчик. Код лежит в `modules/` и выполняется по порядку в одном пространстве имён: ядро и база, оплата, роли и клавиатуры, медиа, команды, FAQ и кабинеты, обратная связь, достижения, удержание, перевод, голос и файлы, списки, ссылки, обработчики сообщений и колбэков, business-события, запуск.

## Файлы вне репозитория
- `offer.txt` — текст публичной оферты;
- `local_api.txt` — адрес локального Bot API (например `http://127.0.0.1:8081`), нужен для файлов больше 20 МБ (до 200 МБ). Без него действует лимит облачного Bot API;
- `mtproto.json` — необязателен.
