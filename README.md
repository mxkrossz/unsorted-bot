# unsorted-bot

Telegram Business бот unsorted: сохраняет удалённые и изменённые сообщения, одноразовые медиа, Premium-тарифы, рефералы, промокоды, достижения, обратная связь.

Стек: Python, aiogram 3, SQLite.

Перед запуском подставь свой токен в BOT_TOKEN и свой ID в ADMIN_ID в bot.py. Текст публичной оферты положи в offer.txt.
